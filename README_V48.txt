FLEVO v4.8 — Dashboard & Deployment Readiness

الجديد:
1) dashboard.html لوحة قيادة مركزية بمؤشرات المشروعات والطلبات.
2) روابط وصول سريعة لكل وحدات الإدارة.
3) manifest.webmanifest لدعم تثبيت الموقع على الهاتف.
4) robots.txt و sitemap.xml للتهيئة لمحركات البحث.
5) صفحة 404 مخصصة.
6) إضافة metadata أساسية للصفحات العامة.

قبل النشر النهائي:
- استبدل https://www.flevo.com في robots.txt و sitemap.xml بالدومين النهائي إذا اختلف.
- اختبر dashboard.html بعد تسجيل الدخول.
- لا تنشر مفاتيح service_role أو أي أسرار داخل الملفات.
